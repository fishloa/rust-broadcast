# broadcast-matroska docs

The user-facing documentation is the crate [README](../README.md) and the
crate-root `//!` comment.

The standards this crate implements are transcribed in the private companion
repository; nothing is copied into the public tree:

- EBML: `private/specs-verified/ietf/specs/rfc8794_ebml.txt`.
- Matroska: `private/specs-verified/ietf/specs/rfc9559_matroska.txt`.
- The demux-relevant element subset:
  `private/specs-verified/mpeg/transmux/webm/ebml-matroska.md`.
