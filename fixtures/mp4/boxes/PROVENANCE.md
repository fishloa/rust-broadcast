# Tier 1 box fixtures

Small files produced by GPAC (`MP4Box`) from a committed source, each carrying
the tier 1 boxes the crate now types. The source for every file is
`fixtures/mp4/h264-aac-prog.mp4` (2 s, one AVC video track and one AAC audio
track, written by Lavf); the DASH fixture starts from a 6 s AVC/AAC file
generated by the documented `ffmpeg` command.

Tool versions used: `MP4Box - GPAC version 26.07-revrelease` and
`ffmpeg version 8.1.2`.

## `track-description.mp4`

Carries `trgr` (a `msrc` group), `elng` and `kind`.

```sh
MP4Box -add fixtures/mp4/h264-aac-prog.mp4:tkgp=msrc,1 \
       -lang 2=en-US \
       -kind 2=urn:mpeg:dash:role:2011=main \
       -new fixtures/mp4/boxes/track-description.mp4
```

`mp4dump` prints the three boxes:

```
    [trgr] size=8+16
      [elng] size=8+10
    [trgr] size=8+16
      [kind] size=8+33
```

The audio track's `elng` string is `en-US`; its `kind` is
`urn:mpeg:dash:role:2011` with value `main`; both tracks carry a `msrc` group
with `track_group_id` 1.

## `track-group-ster.mp4`

Carries a `ster` group written by GPAC without the optional-looking trailing
`left_view_flag` word (the box is 16 bytes: header, version/flags and
`track_group_id` only).

```sh
MP4Box -add fixtures/mp4/h264-aac-prog.mp4:tkgp=ster,1 \
       -new fixtures/mp4/boxes/track-group-ster.mp4
```

The crate parses it with `left_view_flag` absent and round-trips the bytes
unchanged; a conformant `ster` with the flag word is covered by the
hand-assembled test.

## `ssix-sidx.mp4`

A single-file DASH presentation whose media segments carry `sidx` followed by
`ssix` (the GPAC `-ssix` option).

```sh
ffmpeg -y -f lavfi -i testsrc=duration=6:size=160x120:rate=25 \
       -f lavfi -i sine=frequency=440:duration=6 \
       -c:v libx264 -g 25 -pix_fmt yuv420p -c:a aac -shortest gen.mp4
MP4Box -dash 1000 -subsegs-per-sidx 1 -ssix -out seg.mpd gen.mp4
```

`mp4dump` prints five `[sidx] size=12+32` / `[ssix] size=8+20` pairs. Each
`ssix` has `subsegment_count` 1 and two ranges; the first segment's ranges are
level 1 / 3236 bytes and level 2 / 12184 bytes.

## Boxes no installed tool produced

GPAC 26.07 and ffmpeg 8.1.2 expose no switch or import option that writes
`ludt`/`tlou`/`alou`, `chnl`, `dmix`, `labl`, `tsel`, `stvi`, `leva`, `pdin`,
`trep`, `csgp`, `stdp`, `padb` or `stsg` (searched `MP4Box -h all`,
`gpac -hx` and the import/dash help; `-group-add` writes only the `tkhd`
alternate/switch group fields, not `tsel`; `-ssix` is the only index option).
Their tests in `isobmff/tests/it/tier1_boxes.rs` use bytes hand-assembled from
the clause and are labelled as such.
