## CPIX key-exchange fixtures (`fixtures/cpix/`)

Prep work for issue #745 (multimux DRM key-server integration). See `private/specs-verified/dash/cpix/`
for the full transcription these fixtures support.

Not vendored from the same repo (available upstream if a later implementation phase
needs them, but not needed for spec-transcription/fixture prep): the X.509
test-certificate `.cer`/`.pfx` pairs, and the intentionally-invalid
`Invalid_BadContentKeysSignature.xml` / `Invalid_BadDocumentSignature.xml` /
`Invalid_WrongMac.xml` negative fixtures.

**Verified with our own tooling** (no `cpix` crate exists yet to parse these with, so
verification used the same class of independent tooling this project already trusts for
non-Rust fixture checks — Python's standard-library `xml.etree.ElementTree`, analogous to
`xmllint --noout`):

- All five `.xml` files above parse as well-formed XML with `xml.etree.ElementTree`,
  root element `{urn:dashif:org:cpix}CPIX` in every case (element counts: 18, 226, 51,
  34, 37 respectively).
- `widevine-pssh-from-complex.bin` was independently re-derived from `Complex.xml` (a
  second, from-scratch decode script, not a copy of the one used to produce the
  committed file) and compared byte-for-byte: **identical**, 56 bytes,
  `000000387073736800000000edef8ba979d64acea3c827dcd51d21ed000000181210b4c3188beddd453d9bc21cbca756623948e3dc959b06`.
