# PAFF (field-coded) H.264 test fixtures

Synthetic, spec-built streams (no third-party content). Licence: MIT OR Apache-2.0, (c) 2026 Alex Fishlock.

- `paff-tff-12f-64x64.ts` / `paff-bff-12f-64x64.ts`: 12 frames, 64x64, every picture a FIELD (`field_pic_flag = 1`), top-field-first / bottom-field-first, one PES per field, PTS per field (frame period 3600, field offset 1800 at 90 kHz), all macroblocks I_PCM so the decode is lossless.
- `*.yuv`: the expected decoder output (woven yuv420p frames, decode order).

Generated by `transmux/tests/it/support/paff_gen.rs` (vendored from the zenith-tv `paff-gen` tool, written from ITU-T H.264 sections 7.3, 7.4, 8.3.5 and Annex B, and ISO/IEC 13818-1 only). Regenerate with:

    cargo run -p transmux --example regen_paff_fixtures -- --write

(the same command without `--write` only prints the digests below). No `cargo test` invocation can rewrite these files.

No real broadcast PAFF capture is committed (not redistributable); `private/fixtures` was checked and holds none.
