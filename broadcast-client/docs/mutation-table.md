# Mutation table (design step W-b)

Each mutant is a one-line change to production source, applied on its own and followed by the tests that cover it (`cargo test -p broadcast-client --all-features --locked --no-fail-fast --lib --test dash_clock_surface`, and for `dash-runtime` mutants first `cargo test -p dash-runtime --locked --no-fail-fast --test client_config --test datetime --test label_coverage`), then reverted. The harness `mutants.py` in this directory holds the exact edits (`--dry` checks that every pattern still matches exactly once) and prints `recompiled=True` when the edited crate was rebuilt for that run; every run below recompiled. A mutant is **killed** when at least one test fails.

Result: 40 of 41 mutants killed, 1 equivalent (W38). The first run left two survivors: W40 (the HTTP-date trim, unreachable through the IMF form because the RFC 2822 reader tolerates the whitespace itself; the obsolete forms need it, and a test with padded RFC 850 and asctime inputs now kills it) and W38 (equivalent, see its row).
