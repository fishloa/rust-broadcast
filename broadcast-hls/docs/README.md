## Private spec transcriptions

The transcriptions of RFC 8216bis (`draft-pantos-hls-rfc8216bis-22`), RFC 8216 and the Apple HLS Authoring Spec for this crate live only in the private companion repository `rust-broadcast-private` (the `private/` submodule) under `private/specs-verified/hls/` (`ietf/`, `apple/`, `broadcast-hls/`). Both IETF texts carry the notice "This document may not be modified, and derivative works of it may not be created", and Apple's documents are not freely licensed, so none of that text is published here. Old public path to private path: [`docs/specs/PRIVATE-MAP.md`](../../docs/specs/PRIVATE-MAP.md); code comments keep their original `docs/...` citations.

Moved from this directory: `playlist-tags.md`, `low-latency.md`, `server-requirements.md`, `media-segment-formats.md`, `version-compatibility.md`, `interstitials.md`, `examples.md`, `ext-x-key.md`, `iframe-playlists.md`, `multivariant-attribute-rules.md`.

Still public in this directory: `NOTES.md` (own words).
