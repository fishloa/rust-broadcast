# ETSI EN 300 468 v1.19.1 -> v1.20.1 delta

Method: `diff` of `private/specs-md/etsi_en_300_468_v01.19.01_dvb_si.md` against
`..._v01.20.01_dvb_si.md` (1971 diff lines, read in full; the great majority is
OCR/layout reflow of the two PDF extractions). v1.20.1 is dated 2026-09; its
change history (Annex Q) lists: interim draft 2025-02 "Added AVS3-P3 audio
signalling", "Changed Table 11h indentation", "Clarified use of
interpolation_flag == 0 in several locations", "Relating to newer DVB-S2Xv2
content copied from an external space-related specification" (BlueBook A038r18:
"Changed from 'reserved' to 'undefined and not used'"; small `aac_descriptor`
reference fix), October 2025 draft "Added clarification of MJD date and time
behaviour in 2038 wrap-around", "Added TUWA 0005 signalling" (BlueBook A038r19).

**There is no new `descriptor_tag`, `descriptor_tag_extension`, `table_id`,
`satellite_table_id`, linkage_type, service_type or content_nibble value in
v1.20.1.** Every wire layout is unchanged. The substantive changes, with the
dvb-si disposition of each, are:

## Reserved-bit policy changes

None beyond #3 (flags/fields in satellite_position_v3_info are now "not used" /
"undefined", not "reserved"): parse tolerant, serialize preserves the parsed
value (already the case). Hand-built defaults for genuinely `reserved_zero_future_use`
runs stay `0` (edition spec value); `reserved-bits-edition-audit.md` needs no
change because no reserved run changed value or width.
