# mpeg-ts 0.9.0

_Released 2026-11-15._

### Changed
- BREAKING: `SiMux` schedules one complete `Section` at a time keyed by the new `SectionKey` (`(pid, table_id, section_number)`), and `poll`/`poll_into` take the caller's `broadcast_common::stage::Timestamp` instead of a `Duration` (#2763). The packetiser derives `section_length` and the CRC from the section itself, so an empty `Vec` can no longer collide with the PAT entry on PID 0, a batch of mixed-table sections cannot share one entry, and a truncated trailing section cannot be dropped without a word; a section that cannot be scheduled is returned and kept for `SiMux::rejected` (`RejectedSection`/`SectionRejection`). The convenience registrations (`upsert_pat`, `upsert_pmt`, `upsert_sdt_actual`, `upsert_nit`, `upsert_tdt`, `upsert_tot`) return `Result` and refuse another table's section, since a PAT interval used to apply to whatever sat under `table_id 0`; the six `TABLE_ID_*` constants name the `table_id` each one expects.
- `TsResync` reports the bytes before the first lock as a `ResyncLoss` too: they were counted in `ResyncStats::dropped_bytes` but never surfaced, so a capture that starts mid-packet disagreed with `take_losses()` (#2765). Every byte in `dropped_bytes` is now accounted for by a loss.
- `TsPacket::parse`, `extract_ts_payload`, `OwnedTsPacket::adaptation_field`, `OwnedTsPacket::set_pcr`/`set_opcr` and `ts_dup`'s PCR exemption all locate the adaptation field and its PCR/OPCR through one shared locator instead of four hand-rolled copies with their own byte offsets and flag walks (#2772). Behaviour is unchanged on every real packet; a truncated slice still reports the field as unreachable rather than reading past it.
### Added
- `OwnedTsPacket::set_opcr` rewrites the OPCR in place, and `Pcr::to_field_bytes_with_reserved` encodes the 6-byte field keeping a packet's own reserved bits (#2764).
- `TsHeader::to_bytes`: the 4 header bytes, infallibly encoded (sets `[0] = 0x47`, the PID/adaptation-control/scrambling/counter fields). `serialize_into` now copies from it, and the packet builders use it directly so a fixed-size header write can no longer go through a fallible `serialize_into` (#2773).
### Changed
- `OwnedTsPacket::set_pcr` reports the three distinct causes with three distinct errors instead of one fabricated `BufferTooShort { need: 6, have: 0 }`: `Error::NoAdaptationField` (no adaptation field, or a zero-length one), `Error::AdaptationFieldTooShort { need, have }` (the declared field is too small for the flags byte plus the PCR), and `Error::NoClockReference { which }` (the packet's own PCR flag is clear). It also keeps the packet's existing PCR reserved bits instead of forcing them to `1`, so an in-place rewrite of a captured packet changes the 6 PCR bytes and nothing else (#2764).
- BREAKING: `Section` no longer stores a CRC or a `section_length` (#2749). The CRC is recomputed on every serialize, so a section whose payload was edited can no longer carry a stale one; `section_length` is derived from `payload` (`section_length()`), so a long payload is checked against the 12-bit field (`Error::FieldOverflow`) instead of being truncated and a short one is simply written; `version_number` is `fit_bits`-checked the same way. `crc32` is now the read-only `crc32()` accessor (`parsed_crc32` is private), `validate_crc(&raw)` is the free function `mpeg_ts::section::validate_crc` (it needs only the wire bytes), `Section::validate_crc()` takes no argument, `Error::SectionPayloadLengthMismatch` is removed, and the byte 1 / byte 5 reserved bits are parsed and round-tripped (`byte1_reserved`/`byte5_reserved`) rather than forced to `11`.
- BREAKING: adaptation-field extension and PCR reserved bits are checked, not masked, on serialize (#2748). `Ltw::ltw_offset` is the new 15-bit `LtwOffset` and `AdaptationFieldExtension::piecewise_rate` the new 22-bit `PiecewiseRate` (both `new`/`get`/`MAX`, re-parsing through `from_wire_masked`); `SeamlessSplice::to_marked_field` and `AdaptationField::serialize_into` reject an out-of-range `splice_type`, `DTS_next_AU` (33 bits, exposed as `SeamlessSplice::DTS_NEXT_AU_BITS`), marker bits, `ltw_offset`, `piecewise_rate` or `pcr_reserved`/`opcr_reserved` with `Error::FieldOverflow` instead of writing a different valid value (an over-range `pcr_reserved` shifted into the PCR base bits).
- BREAKING: `TsHeader` carries typed fields (each is a wire field, parsed losslessly: an unknown or reserved value is kept, never rejected). `scrambling: u8` is now `ScramblingControl`, `has_adaptation`/`has_payload` are replaced by one `adaptation_field_control: AdaptationFieldControl` (with `has_adaptation()`/`has_payload()` accessors, so the reserved `00` that `(false, false)` used to express is named), and `continuity_counter: u8` is the new 4-bit `ContinuityCounter` (`try_new`, `from_wire_masked`, `next()`, `forward_distance_from()`). `TsHeader::scrambling_control()`/`adaptation_field_control()` (and `OwnedTsPacket::scrambling_control()`) are gone because the fields themselves are typed; `serialize_into` no longer masks, so an out-of-range counter cannot be written (#2656).
- BREAKING: `OwnedTsPacket::serialize_with_payload(.., cc: u8, ..)`, `null_packet(cc: u8)`, `set_continuity_counter(.., cc: u8)` and `SectionPacketiser::with_continuity(pid, cc: u8)` take `ContinuityCounter`; `OwnedTsPacket::continuity_counter()` and `SectionPacketiser::continuity_counter()` return it; `SectionReassembler::feed_with_continuity` takes it (#2656).
- BREAKING: `Pid::new` is removed. Constants use `Pid::from_const` (a `const fn` that fails compilation above 0x1FFF), caller values use the fallible `Pid::try_new`, and parse sites use `Pid::from_wire_masked` (the explicit masking constructor, H.222.0 §2.4.3.2); nothing masks silently any more (#2656).
- BREAKING: `Pcr` wraps the validated `broadcast_common::clock33::Clock27`: constructing is strict (`Pcr::from_parts(base, extension)` / `Pcr::from_27mhz(ticks)` return `Result`, out-of-range parts are `Error::ClockOutOfRange`), the `base`/`extension` fields are the `base()`/`extension()` accessors, and `clock()` yields the shared value. Parsing is lossless: the 9-bit wire extension can be 300..=511 (off the 27 MHz clock) in real captures, so `AdaptationField::parse` keeps such a PCR exactly as written and it re-serializes byte-identically; the new checked `Pcr::to_clock27()` reports it as `Error::ClockOutOfRange`. The wire extension is now decoded into a `u16` directly (`(extension[8] as u16) << 8`); a `u8` shift would drop bit 8 (#2656).
- BREAKING: `SiMux::upsert` takes a `SectionInterval` (`SectionInterval::try_new(Duration)` / `from_const`), enforcing the EN 300 468 §5.1.4.1 25 ms floor at construction rather than by a `debug_assert!` that release builds compiled out; the `*_MAX_INTERVAL` constants are `SectionInterval`s (`#2656`).
- The `serde` feature enables `broadcast-common/serde`, since `Pcr` serializes the shared clock value.
