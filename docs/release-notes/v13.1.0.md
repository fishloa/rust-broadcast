# v13.1.0

_Released 2026-11-10._

Lockstep **minor** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 13.0.0 -> 13.1.0. No breaking changes: additive and fix release. `dvb-tools` carries the version only.

## Highlights

- **`dvb-si`:** `TableId`, `DescriptorTag` and `ExtensionTag` now implement the workspace label convention (`name()` + `Display` via `broadcast_common::impl_spec_display!`).
- **`dvb-si` carousel/demux robustness:** `ModuleReassembler` no longer grows its completed-module FIFO per version and replaces a DII repeat announcing the same module version with changed geometry; `SiDemux` no longer appends a retransmitted continuation packet, keeps the full PMT PID watch set across multi-section PATs, ignores `current_next_indicator = 0` PATs, and keys its version gate on `current_next_indicator`.
- **`dvb-conformance`:** CRC-failed SI sections no longer mutate monitor state; `_other` repetition errors re-raise on every later outage; 2.3a/2.3b PCR checks sharpened (27 MHz comparison, silence detection, once-per-gap reporting); legal duplicate packets are not fed to section reassembly; EIT P/F vanishing partner detected; PES packets without an optional header skipped in 2.5; EIT P/F pairing map bounded.
- **`dvb-bbframe`:** `CarryOverExtractor`/`BbframePump` reset the NM CRC-8 chain and pending partial UP on a skipped frame; a `SYNCD=0xFFFF` frame keeps the data-field bytes after the UP it completes.
- **`dvb-stream`/`mpeg-ts` fixes consumed:** byte-stream `TsDecoder` re-locks one packet at a time; `SectionReassembler` no longer loses a multi-packet section to a retransmitted continuation; `TsResync::finish` keeps aligned tail packets.

## Fixed
