# v15.1.0

_Released 2026-11-17._

Lockstep minor (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 15.0.0 -> 15.1.0. Two of the five carry a functional change; the other three are version-only and follow the family.

- `dvb-si` 15.0.0 -> 15.1.0: the `SiDemux` version gate evicts per PID, so a flood of distinct keys on one PID can no longer evict a legitimate PID's entries. See `dvb-si-15.1.0.md`.
- `dvb-conformance` 15.0.0 -> 15.1.0: adds `ConformanceMonitor::declares_pcr_pid`, which reports whether a PID is the `PCR_PID` the latest PMT of a PAT-referenced program declares. See `dvb-conformance-15.1.0.md`.
- `dvb-bbframe` 15.0.0 -> 15.1.0: dependency/epoch bump only. See `dvb-bbframe-15.1.0.md`.
- `dvb-t2mi` 15.0.0 -> 15.1.0: dependency/epoch bump only. See `dvb-t2mi-15.1.0.md`.
- `dvb-tools` 15.0.0 -> 15.1.0: dependency/epoch bump only. See `dvb-tools-15.1.0.md`.

`broadcast-common` moves 13.0.0 -> 13.1.0 and is published first, from tag `broadcast-common-v13.1.0`. `compliance-probe` uses `dvb-conformance`'s new `declares_pcr_pid` to restrict its per-PCR-PID series.
