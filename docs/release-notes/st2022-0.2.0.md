# st2022 0.2.0

_Released 2026-10-16._

**Breaking release (own API change plus the `broadcast-common` 10 epoch).** `PayloadHeader::extension` is now a typed TLV view (`Option<HeaderExtension>`) instead of raw bytes, and `PayloadHeader::validate` rejects a `Reserved(code)` that holds a defined code. The README is restructured (scope, standards-supported table, feature table, doctested quick start).

## Why this version

- **Proposed version:** 0.1.0 -> **0.2.0** (major-class: 0.x minor-epoch bump).
- **Own API/behaviour change class:** major (PayloadHeader::extension typed).
- **cargo-semver-checks vs live 0.1.0 (all features):** none flagged. (Lint-based: it misses type changes of existing fields/arguments, so the CHANGELOG BREAKING list is the primary evidence.)
- **Epoch cascade:** none needed (own breaking change). Siblings it depends on that move epoch in this wave: broadcast-common.
- **Caret epoch:** 0.1 -> 0.2; every workspace dependent must move with it.

## Breaking changes and migration

`broadcast-common` 9 -> 10: resolve a single `broadcast-common` 10 in your tree; `Serialize::to_bytes` is gone, use `try_to_bytes()?`.

`PayloadHeader::extension` is no longer `&[u8]`:

```rust
// before
let raw: &[u8] = header.extension;
// after
if let Some(ext) = header.extension {
    let raw: &[u8] = ext.as_bytes(); // the wire octets, exactly as parsed
    let _ = ext.len();               // Ext * 4 octets
}
for item in header.extension_items() {
    match item? {                    // Result<ExtensionItem, Error>
        ExtensionItem::Pad => {}
        ExtensionItem::Tlv { tag, value } => { let _ = (tag, value); }
    }
}
// building a header: wrap the octets (non-zero multiple of 4, at most 60)
let ext = HeaderExtension::new(&octets)?;
```

`validate` now fails a `Reserved(code)` variant whose code is a defined one (it used to serialize as the defined code and parse back as the named variant, so the value did not round-trip); construct the named variant instead.

A malformed TLV chain still round-trips byte-identically and is reported by the item walk.

## What changed (from CHANGELOG `[Unreleased]`)

#### Documentation
- README restructured: what the crate does and does not do, a standards-supported table (edition, scope, status), feature-flag table, a doctested quick start and related crates; crate-root docs now render the README (or are kept in step with it).

#### Changed (BREAKING: epoch — requires broadcast-common 10)
- Builds against new caret epochs of workspace siblings (`broadcast-common` 9 -> 10). A caret-epoch change is major-class for this crate under the epoch-purity rule (`docs/RELEASE-AUDIT.md` §2), whatever its own API diff. `Serialize::to_bytes` was removed (use `try_to_bytes`); consumers must resolve a single `broadcast-common` 10.

#### Changed
- **BREAKING:** `PayloadHeader::extension` is now `Option<HeaderExtension<'a>>`
  (typed TLV view: `HeaderExtension::new`, `items()`, `ExtensionItem::{Pad, Tlv}`,
  `PayloadHeader::extension_items()`), not a raw `&[u8]`; a malformed TLV chain
  still round-trips byte-identically and is reported by the item walk (r13-S22-W1, #1115).

#### Fixed
- `PayloadHeader::validate` rejects a `Reserved(code)` variant that holds a
  defined code (it serialized as the defined code and parsed back as the named
  variant, breaking the value round-trip) (r13-S22-W2, #1115).
