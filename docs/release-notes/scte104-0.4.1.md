# scte104 0.4.1

Security patch. **Upgrade if you parse or relay SCTE 104 messages from the network.** Drop-in for
0.4.x.

## Security

**GHSA-mgg2-9ggf-xq48** — before this release, `SingleOperationMessage::parse` accepted a
`messageSize` smaller than the 13-byte message header. Re-serializing that message then indexed
past its buffer and panicked. One 13-byte network message was enough to crash a relay.

## Changes

- **Parse:** a `messageSize` below the header length is rejected with `BufferTooShort`.
- **Serialize:** `messageSize` is derived from the encoded fields, so it can't disagree with the
  bytes written. A message too large for the 16-bit `messageSize` field is an error rather than
  a silently truncated length.
