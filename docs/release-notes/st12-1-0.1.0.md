# st12-1 0.1.0

**Release date:** 2026-07-12

Initial release. `st12-1` parses and serializes the SMPTE ST 12-1:2014
80-bit Linear Timecode (LTC) codeword -- the standard timecode format
carried as a biphase-mark-encoded signal in professional video/audio
production environments.

## What's new

- `LtcFrame` -- parser/serializer for the 80-bit LTC codeword: BCD
  hours/minutes/seconds/frames, drop-frame and color-frame flags, eight
  4-bit binary groups (user bits), and the fixed synchronization word.
- `FrameRate` -- selects which of Table 3's three flag-bit-position columns
  (30-frame/25-frame/24-frame) applies to the four rate-dependent flag bits.
- `BinaryGroupUsage`/`BinaryGroupFlags` -- Table 1's classification of
  binary group contents from the three BGF bits.
- Spec-derived test vectors computed directly from ST 12-1 Tables 2-5 bit
  diagrams, independent of the crate's own serializer.
- Two runnable examples: `build_frame` and `parse_frame`.
- `no_std` (no heap allocation); builds on bare-metal targets.
- `serde` support behind the `serde` feature.
- Fuzz target exercising `LtcFrame::parse` + round trip.

## Migration

No breaking changes. Initial release.
