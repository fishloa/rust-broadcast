# v16.0.0

_Released 2026-11-22._

Lockstep major (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 15.1.0 -> 16.0.0. Every member takes the major because the family builds against `broadcast-common` 14 (the `jiff` 1.0 epoch) and `mpeg-ts` 0.10, a caret-epoch change that is major-class under the epoch-purity rule (`docs/RELEASE-AUDIT.md` §2). Two members also carry their own breaking change: the `num_enum` removal and jiff 1 types in `dvb-si`, and the `num_enum` removal in `dvb-t2mi` and `dvb-bbframe`.

- `dvb-si` 15.1.0 -> 16.0.0: `TableId`, `DescriptorTag` and `SatTableId` convert through hand-written `TryFrom` impls whose error is the crate's own `Error` instead of `num_enum::TryFromPrimitiveError`; jiff-decoded times are jiff 1.x; and `epg::PresentEventTracker` follows one service's EIT present/following present event. See `dvb-si-16.0.0.md`.
- `dvb-t2mi` 15.1.0 -> 16.0.0: `PacketType`, `FrequencySource`, `S1Field`, `Bandwidth`, `SubpartVariety`, `PrbsType` and `AddressingFunctionTag` convert through the crate's own `TryFrom` errors, and jiff-decoded times are jiff 1.x. See `dvb-t2mi-16.0.0.md`.
- `dvb-bbframe` 15.1.0 -> 16.0.0: `TsGs` and `Mode` convert through the crate's own `TryFrom` errors. See `dvb-bbframe-16.0.0.md`.
- `dvb-conformance` 15.1.0 -> 16.0.0: per-PID `TBn` `Empty_buffer_error` (TR 101 290 indicator 3.9) can now fire, because each PID's transport buffer arms its empty-interval window at creation. See `dvb-conformance-16.0.0.md`.
- `dvb-tools` 15.1.0 -> 16.0.0: lockstep version only; the CLI surface is unchanged. See `dvb-tools-16.0.0.md`.

## Migrating

1. Move to `broadcast-common` 14 and `jiff` 1.x. The `jiff` speller is unchanged for what these crates return (`jiff::Timestamp::from_second`, `as_microsecond`, `jiff::SignedDuration::from_secs`), but a `jiff` 0.2 value no longer unifies.
2. Replace a match on `num_enum::TryFromPrimitiveError<_>` with the crates' own errors: `dvb_si::Error::InvalidValue` (naming the field and the rejected value), `dvb_t2mi::Error::InvalidPacketType`/`InvalidValue`, `dvb_bbframe::Error::UnsupportedTsGs`/`InvalidMode`.
3. `dvb-si` with the `ts` feature builds against `mpeg-ts` 0.10; resolve a single copy of each.

`broadcast-common` moves 13.1.0 -> 14.0.0 and is published first, from tag `broadcast-common-v14.0.0`. `mpeg-ts` 0.10.0 is published before this tag.
