# media-plane 0.2.0

**Release date:** 2026-08-02

Adds `ArchiveOverrun` policy for DVR retention overflow and additional cursor/ring capacity improvements.

## What's new

- `ArchiveOverrun` policy — configurable behaviour when the DVR archive runs out of retention budget.
- Cursor and ring capacity improvements.

## Migration

Requires `transmux` 0.22.
