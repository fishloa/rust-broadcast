# v15.0.0

_Released 2026-11-15._

Lockstep **major** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 14.0.0 -> 15.0.0. Three things make it a major:

- **`dvb-si` breaking change:** every fixed-width reserved field is the shared typed `broadcast_common::reserved` value, and `SiDemux::builder()` is replaced by `SiDemux::new(SiDemuxConfig)` (#2738, #2737).
- **`chrono` -> `jiff`:** the `chrono` feature is replaced by `jiff` (no alias) across the family, which changes the type of every decoded instant (`dvb-si`, `dvb-t2mi`) and the `epg` output format (`dvb-tools`) (#2635).
- **Epoch purity:** `broadcast-common` moves 12 -> 13 and `mpeg-ts` moves 0.8 -> 0.9, so every lockstep crate builds against new caret epochs of its siblings, which is a major-class change on its own (docs/RELEASE-AUDIT.md section 2).

## Breaking changes and migration

`SiDemux` is built from a non-exhaustive `SiDemuxConfig` instead of a builder:

```rust
// before
let demux = SiDemux::builder().pid(pid).build();
// after
let demux = SiDemux::new(SiDemuxConfig::default().with_pid(pid));
```

Reserved fields are `ReservedOnes<BITS>`/`ReservedZero<BITS>`: assign with `ReservedOnes::from_bits(v)` / `ReservedZero::from_bits(v)` and read with `.get()`. The full descriptor and table list is in `dvb-si-15.0.0.md`.

Every decoded instant is a `jiff::Timestamp` (local time offsets a `jiff::SignedDuration`), and `EitEvent::start_time_chrono` is renamed `start_time_utc`:

```rust
// before (dvb-si with the chrono feature)
let start: chrono::DateTime<chrono::Utc> = event.start_time_chrono()?;
// after (jiff is the default feature)
let start: jiff::Timestamp = event.start_time_utc()?;
```

`dvb-t2mi`'s `T2TimestampPayload::emission_time_utc`/`set_emission_time_utc` take and return `jiff::Timestamp` instead of `chrono::DateTime<Utc>`:

```rust
// before
let t: chrono::DateTime<chrono::Utc> = payload.emission_time_utc();
// after
let t: jiff::Timestamp = payload.emission_time_utc();
```

A `dvb-tools` user reading `epg` output gets RFC 3339 with a `Z` suffix where it used to print `+00:00`.

## Fixes

- **`dvb-si`:** ISO/IEC 8859-2 … -15 text (selectors 0x01–0x0B and `0x10 0x00 nn`) is decoded from tables in the crate, so it decodes under `no_std` instead of yielding U+FFFD and no longer needs `encoding_rs`. `encoding_rs` now sits behind the `legacy-charsets` feature (on by default) and covers only the KS X 1001, GB-2312 and Big5 selectors.

## Highlights

- **`dvb-si`:** a zero gate capacity is unrepresentable (`with_gate_capacity` takes a `NonZeroUsize`), so a demux that retains nothing can no longer be built silently; `text::LegacyCharset` names the three legacy charsets and `Error::CharsetNotEnabled { charset }` reports one with the feature off.
- **`dvb-t2mi`:** no functional change beyond the timestamp type (it follows `broadcast-common`, `dvb-bbframe` and `mpeg-ts`).
- **`dvb-bbframe` and `dvb-conformance`:** dependency/epoch bump only; no functional change (see their own notes).

See the per-crate notes for the full lists: `dvb-si-15.0.0.md`, `dvb-t2mi-15.0.0.md`, `dvb-bbframe-15.0.0.md`, `dvb-conformance-15.0.0.md`, `dvb-tools-15.0.0.md`.

## Dependencies

- `broadcast-common` 12 -> 13 (published first, from tag `broadcast-common-v13.0.0`).
- `mpeg-ts` 0.8 -> 0.9 (published before this tag, from tag `mpeg-ts-v0.9.0`).
- `dvb-bbframe` 14 -> 15 is published first within the family (it has no lockstep sibling), then `dvb-si`, `dvb-conformance`, `dvb-t2mi`, `dvb-tools`.
