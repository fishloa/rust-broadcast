# dash-runtime 0.5.0

_Released 2026-11-15._

### Changed
- BREAKING: the public wall-clock and media-time surface is `jiff::Timestamp`/`Duration`/`SignedDuration`, not microsecond integers (#2730). `address::DynamicContext` is `{ availability_start: jiff::Timestamp, time_shift_buffer_depth: Option<Duration>, availability_time_offset: jiff::SignedDuration, horizon_utc: Option<jiff::Timestamp> }` (and `new` takes those), `address::PlanInput` is `{ period_start: Duration, period_end: Option<Duration> }`, `address::SegmentRef`/`address::ResourceRef` carry `start: jiff::SignedDuration`, `duration: Duration`, `available_from`/`available_until: Option<jiff::Timestamp>`, `SegmentPlan::period_start()`/`available_from()`/`available_until()`/`index_at_or_before(jiff::SignedDuration)` replace `period_start_us()`/`available_from_us()`/`available_until_us()`/`index_at_or_before(i128)`, `PlanOptions::horizon_utc`/`with_horizon` replace `horizon_utc_us`/`with_horizon_utc_us`, `timing::period::PeriodTiming` is `{ start: Option<Duration>, end: Option<Duration> }`, `timing::availability::ato_seconds` returns a `jiff::SignedDuration` (replacing `ato_seconds_to_us`), `timing::live_edge::{presentation_delay, join_time}` take/return `Duration`/`SignedDuration` (replacing `presentation_delay_us`/`join_time_us`), `timing::clock::Anchor::utc` is a `jiff::Timestamp` and `uncertainty` a `Duration` (replacing `utc_us`/`uncertainty_us`), `UtcClock::utc_at`/`mono_for_utc` take/return `jiff::Timestamp`, and `timing::utc_timing::UtcSample` is `{ mono: Timestamp, utc: jiff::Timestamp, uncertainty: Duration }`. The `utc_us` `Anchor`/`UtcSample` fields and the `*_us` media-time fields are removed; the internal `i128` microsecond arithmetic stays internal.

- BREAKING: `address::AddressError::Sidx` and `ingest::SessionError::Demux` wrap a `transmux::Error` (via `#[from]`) instead of a formatted `String`, so callers branch on the typed failure rather than its message text. `AddressError`, `PlanError` and `SessionError` are `PartialEq` but no longer `Eq` (`transmux::Error` is not `Eq`) (#2734).
- BREAKING: `client::ResponseMeta` and `client::UtcResponse` carry typed headers: `date: Option<headers::Date>`, `etag: Option<headers::ETag>`, `last_modified: Option<headers::LastModified>` (was `Option<&str>`), and their `with_date`/`with_etag`/`with_last_modified` take those types. `ResponseMeta` is `Clone` but no longer `Copy` (an `ETag` owns its value). A header the typed reader refuses is absent, as it is in the response's own header map. Migration: read the value from the host's `http::HeaderMap` with `typed_get::<headers::Date>()` (and the same for `ETag`/`LastModified`) (#2692).

- BREAKING: the clock surface is `Timestamp`/`Duration`, not raw microseconds (#2686). `client::DashConfig`'s spans are `core::time::Duration` (`utc_timeout`, `utc_wait`, `utc_max_rtt`, `host_clock_uncertainty`, `availability_margin`, `early_retry`, `early_grace`, `min_mpd_refresh`; `live_delay: Option<Duration>`), `utc_resync` is `Option<Duration>` (`None` never re-syncs on age, replacing the `u64::MAX` sentinel), and the `DEFAULT_*_US` constants are `DEFAULT_*` `Duration`s with the `_US` names removed. `client::ResponseMeta::sent`/`received` and `client::UtcResponse::sent`/`received` are `Timestamp` (was `sent_us`/`received_us: u64`), `FailureClass::NotYetAvailable::retry_at` is a `Timestamp`, `Output::ClockSynced::uncertainty` is a `Duration`, `timing::utc_timing::Exchange` is `{ sent, received: Timestamp }`, `sample_from_exchange`/`sample_from_body`/`sample_from_date_header`/`sample_from_direct` take `Duration`s (`TimingError::RttTooLarge { rtt, max }`), `timing::clock::Anchor::mono` and `UtcClock::utc_at`/`OfferPolicy::resync` are `Timestamp`/`Duration`, and `DashClient::set_wall_clock(now, unix: jiff::Timestamp)` takes the host's wall clock as a `jiff::Timestamp`. `DashClient::next_wake() -> Option<Timestamp>`. Migration: wrap a microsecond reading in `Timestamp::from_micros(..)`, a span in `Duration::from_micros(..)`, and `Some(unix_us)` in `jiff::Timestamp::from_microsecond(..)`.
- `DashClient` builds every deadline with `Timestamp::checked_add`, so a span past the end of the clock never fires instead of being clamped to `u64::MAX` and staying due forever; the periodic UTC re-sync follows `DashConfig::utc_resync` rather than the default constant (#2686).
- BREAKING: `client::DashClientConfig::new(url)` takes a `url::Url` (not `impl Into<String>`), `DashClientConfig::mpd_url`/`DashClient::mpd_url()`/`DashClient::set_mpd_base` are `url::Url`, and every `client::Action` URL is a `url::Url` (#2655 C2).
- BREAKING: `client::Action`'s ranged fetches carry `byte_range: Option<broadcast_common::range::ByteSpan>` (offset + non-zero length) instead of `Option<(u64, u64)>` (#2655 C1).
- BREAKING: `mpd::base_url::resolve`/`resolve_chain` and `mpd::urls::BaseCandidate::resolve` return `Result<ResolvedRef, ResolveError>` (a new `ResolvedRef::{Absolute(Url), Relative(String)}` and `ResolveError::{ForbiddenChar, SyntheticScheme, Join}`) instead of `Option<String>`, so an absolute URL and a relative reference are distinct and a failure names its cause (#2655 C4).
- BREAKING: `ingest::RequestMeta` is now `#[non_exhaustive]`; build it with `RequestMeta::new(method, path)` + `with_content_length`/`with_chunked`/`with_body_empty` instead of a struct literal (#2664).
- BREAKING: `address::MediaSegment::timescale` and `SegmentPlan::timescale()` are `Timescale` (was `u64`), and `timing::availability::{ticks_to_us, segment_available_from_ticks, segment_available_until_ticks, complete_count_constant}` take a `Timescale`. The zero-timescale branches (a plan with no index offsets, a conversion yielding 0) are gone: a zero `@timescale` is refused by `broadcast-dash` at parse and cannot be constructed here (#2657).
- BREAKING: every `now` `DashClient` takes is a `broadcast_common::stage::Timestamp` (the host's monotonic clock, microseconds) instead of a `now_us: u64`: `poll`, `on_mpd`, `on_mpd_with`, `on_mpd_unchanged`, `on_mpd_failure`, `retry_mpd`, `on_init`, `on_index`, `on_segment`, `on_failure`, `retry`, `skip`, `on_utc_response`, `on_utc_failure`, `set_wall_clock` and `utc_at`. Migration: wrap the host's microsecond reading in `Timestamp::from_micros(now_us)`; the engine's own microsecond arithmetic is unchanged.
- `quick-xml` is a dev-dependency only (its parser is reached through `broadcast-common::xml`), so it no longer appears in the built dependency graph.

### Fixed
- A live MPD refresh deadline that does not fit the clock is no deadline rather than a saturated one: the refresh interval after an update (and after a stale MPD) is added with `checked_add`, so a host clock near the end of its range goes idle instead of waking on every poll forever (#2685).
