# rdd29 0.3.2

Security patch. **Upgrade if you parse Dolby Atmos (RDD 29) frames you do not control.** Drop-in
for 0.3.x.

## Security

**GHSA-6w6c-9736-x7gr** — before this release, `ObjectDefinition1` parsing read the flag byte at
an alignment boundary before checking it was there. A truncated 14-byte body, reached through
`AtmosFrame::parse`, panicked instead of returning an error.

## Changes

- **Parsing:** the byte is bounds-checked first; a truncated body returns `BufferTooShort`.
- **Fuzz target:** the fuzz target is stricter. It previously compared the parser's output with
  a second serialization of itself, so it could never catch a parser that dropped input. Now the
  serialized frame must re-parse to the same value, and when the lengths agree it must match the
  input bytes exactly. The one documented exception is non-minimal `Plex(n)` escapes, which
  decode correctly but re-serialize shorter (docs/rdd29.md §3.4).

MSRV 1.95.0.
