# v12.0.0

_Released 2026-10-16._

Lockstep **major** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`): Twelfth lockstep major. `dvb-si` now brings EN 300 468 up to **V1.20.1**, preserves every `reserved`/`reserved_future_use` bit of every table and descriptor in typed fields (a real sender's section re-serializes byte-identically, CRC recomputed), types every PID as `mpeg_ts::pid::Pid`, and makes serializers reject values wider than their wire field (`fit_mask`, ~220 sites) instead of silently masking them. It also adds the Chinese AVS/GY/T descriptor families, MPEG-H 3D audio, and the MPEG-2 `Extension_descriptor`.

Read together with the wave overview ([2026-10-wave-overview.md](2026-10-wave-overview.md)): `broadcast-common` moves 9 -> 10 and `mpeg-ts` 0.5 -> 0.6 in this same wave, so **every one of the five crates requires both new epochs**; `broadcast-common-v10.0.0` and `mpeg-ts-v0.6.0` must be live on crates.io before this tag is pushed.

## Highlights

- **Typed PIDs** across the family: `mpeg_ts::pid::Pid` replaces `u16` in `dvb-si`, `dvb-t2mi` (`T2miPump::new`, `InnerTsRecovery`), `dvb-conformance` (`ConformanceEvent::pid`).
- **Reserved bits preserved in typed fields** for every table and descriptor in `dvb-si`: real-sender sections re-serialize byte-identically (CRC recomputed).
- **Serializers reject over-range values** (`Error::FieldOverflow`) instead of masking them (~220 sites in `dvb-si`).
- **EN 300 468 V1.20.1** (2038 MJD wrap rule; `CellCenter` -> `CellCentre`; typed `AudioRenderingIndication`).
- **New descriptors:** MPEG-2 `Extension_descriptor` with the MPEG-H 3D audio family, AVS2/AVS3 video and audio, China closed caption (GY/T 270-2013), T/UWA AVS3 video.
- **`dvb-bbframe`:** `Bbheader::serialize()` returns `Result`.
- **`dvb-tools`:** `t2mi --inner` requires `--plp` on a multi-PLP capture; streaming reads (19 MB peak on a 152 MB capture).
