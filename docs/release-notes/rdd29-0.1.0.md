# rdd29 0.1.0

**Release date:** 2026-07-12

Initial release. `rdd29` parses and serializes the SMPTE RDD 29:2019 Dolby
Atmos bitstream format -- the frame/element structure and rendering metadata
(beds, objects, and audio essence pointers) that carries immersive audio
content inside MXF and other container formats.

## What's new

- `AtmosFrame` -- parser/serializer for the RDD 29 ATMOSFrame element:
  version, sample rate, bit depth, frame rate, max rendered objects, and
  sub-element dispatch.
- `AnyElement` -- dispatch enum over the three concrete sub-element types
  plus `Unknown` for reserved/unrecognized element IDs (round-tripped
  verbatim).
- `BedDefinition1` -- channel-based audio bed with `ChannelId` labels
  (Table 6).
- `ObjectDefinition1` -- per-pan-sub-block object rendering metadata:
  position, snap, per-zone gain, spread mode, decorrelation, and audio
  description text.
- `AudioDataDlc` -- audio-essence pointer (AudioDataID + DLCSize + opaque
  DLC payload).
- `distance` module -- decode DistanceXY/DistanceZ position fields to
  linear values.
- `Plex(n)` variable-length integer coding per the spec's escape-doubling
  algorithm.
- Nine spec/field enums with full `name()`/`Display` label pairs.
- Real-fixture test wrapping an E-AC-3 syncframe as opaque DLC payload
  with mutation-bite guard.
- Integration round-trip tests at every frame rate including Plex-escalated
  element sizes.
- Two runnable examples: `build_atmos_frame` and `parse_atmos_frame`.
- `no_std` + `alloc`; builds on bare-metal targets.
- `serde` support behind the `serde` feature.
- Fuzz target exercising `AtmosFrame::parse` + round trip.

## Migration

No breaking changes. Initial release.
