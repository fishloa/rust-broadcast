# st337 0.8.0

_Released 2026-11-22._

Minor for a 0.x crate. No API change of its own: the crate builds against `broadcast-common` 14 (the jiff 1.0 epoch), which is the breaking part. The work is a test pass over the burst-preamble framing.

## Breaking changes

- Builds against `broadcast-common` 14 (its `jiff` 1.0 epoch). A caret-epoch change is major-class under the epoch-purity rule (`docs/RELEASE-AUDIT.md` §2) whatever this crate's own API diff; a consumer must resolve a single `broadcast-common` 14.

## Tests

The ST 337 Table 7 `Pc` burst-info layout is pinned at every field's bit position in both directions, together with all four Table 8 `data_mode` codes, so a 20/24-bit-mode burst can no longer be emitted as 16-bit (#3213).
