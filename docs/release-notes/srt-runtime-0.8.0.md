# srt-runtime 0.8.0

_Released 2026-11-07._

Breaking-class release (0.7 -> 0.8): the error enum wraps the shared kinds, `FieldTooWide` and `ReservedFieldNotZero` are replaced by shared kinds, and sockets can be built over an already-bound `UdpSocket` (#1671).

Version: 0.7.0 -> 0.8.0.

## Breaking changes and migration

What the CHANGELOG records as breaking:

- error variants `BufferTooShort`, `OutputBufferTooSmall`, `InvalidField` now wrap `broadcast_common::error::{BufferTooShort, OutputBufferTooSmall, InvalidField}` (`InvalidField`'s `what` field is `field`); `FieldTooWide { what, value, bits }` is replaced by `FieldOverflow(broadcast_common::error::FieldOverflow)` (`field`, `value`, `max = 2^bits - 1`); `ReservedFieldNotZero { what, value }` is replaced by `ReservedBits(broadcast_common::error::ReservedBits)` (`field`, `expected: 0`, `found`).
- Unused public `FileCc::pkt_snd_period`; `TsbpdScheduler::time_base_us`, `FileCc::set_max_bw_bytes_per_sec` and `GroupFlags::message_number_sync` are now test-only.

### Shared error kinds from `broadcast_common::error`

`broadcast-common` 11 defines the common failure kinds once, as `Copy` structs. This crate's error enum wraps them with `#[error(transparent)] Kind(#[from] broadcast_common::error::Kind)`, so the variants `BufferTooShort` and `OutputBufferTooSmall` (and any other kind named in the list above) changed from struct variants to tuple variants holding the shared struct. The fields are the same, so only the pattern changes, and `From` impls exist, so `?` and `.into()` still build them.

```rust
// before
match err {
    Error::BufferTooShort { need, have, what } => eprintln!("{what}: need {need}, have {have}"),
    _ => {}
}
// after
match err {
    Error::BufferTooShort(e) => eprintln!("{}: need {}, have {}", e.what, e.need, e.have),
    _ => {}
}
```

The display text of these variants now follows the common wording shared by every crate in the wave.

### Renamed and removed items

```text
Error::FieldTooWide { what, value, bits }
    -> Error::FieldOverflow(e)  // e.field, e.value, e.max = 2^bits - 1
Error::ReservedFieldNotZero { what, value }
    -> Error::ReservedBits(e)  // e.field, e.expected (0), e.found
FileCc::pkt_snd_period
    -> (removed; unused)
```

### New: connect or rendezvous over a bound socket (#1671)

`SrtSocket::connect_from_socket` and `SrtSocket::rendezvous_from_socket` take an already-bound `tokio::net::UdpSocket`, so a caller can hold its local port from bind to use. `connect_from_with` and `rendezvous_with` now bind and delegate to them.

## Added

- `arq::seq::contiguous_runs`: inclusive circular runs of consecutive sequence numbers, shared with `broadcast-client`.
- `SrtSocket::connect_from_socket` and `SrtSocket::rendezvous_from_socket`: connect or rendezvous over an already-bound `tokio::net::UdpSocket`, so a caller can hold its local port from bind to use. `connect_from_with` and `rendezvous_with` now bind and delegate to them (#1671).
- `broadcast_common::Parse` / `Serialize` implemented for the crate's wire types, delegating to the existing inherent methods (which stay); each type is round-trip tested through the traits.

## Other changes

- The rendezvous handshake accepts the peer key material in one `accept_peer_crypto` instead of two pasted blocks, and the three handshake `tick`s share `RetransmitStep::into_outputs`.
- `Display` of the handshake state enums is generated by `impl_spec_display!` (same output).

Internal changes with no public effect (shared helpers replacing private copies, README as crate-root docs, `Clone`/`PartialEq`/`Eq` derives on error enums where every field allows it) are listed in the CHANGELOG.

## Dependencies

Workspace sibling requirements move to the new epochs of this wave:

- `broadcast-common` 10 -> 11

These are caret-epoch moves, so a project that names several of these crates must move them together.
