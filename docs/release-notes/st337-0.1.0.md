# st337 0.1.0

**Release date:** 2026-07-12

Initial release. `st337` parses and serializes SMPTE ST 337:2015 non-PCM
audio/data burst-preamble framing over AES3 -- the sync-word + info/length
header that wraps compressed audio (AC-3, E-AC-3, DTS, etc.) for carriage
over a PCM audio channel.

## What's new

- `Burst` -- parser/serializer for one complete ST 337 non-PCM data burst:
  `BurstPreamble` (Pa/Pb sync words, Pc burst-info, Pd length_code, and the
  six-word extended form's Pe/Pf) followed by the opaque burst payload.
- `BurstPreamble` -- data_type, data_mode, error_flag,
  data_type_dependent, data_stream_number, and length_code fields.
- `DataMode` -- Mode16/Mode20/Mode24/Reserved (only Mode16 supported in
  this release).
- `ExtendedPreamble` -- Pe/Pf for extended data types (data_type 31).
- Real-fixture test wrapping a real 834-byte E-AC-3 syncframe with
  byte-identical round-trip coverage and mutation-bite guard.
- Spec-derived edge-case round-trip tests covering zero-length, max-length,
  and extended-preamble forms.
- Two runnable examples: `build_burst` and `parse_burst`.
- `no_std` + `alloc`; builds on bare-metal targets.
- `serde` support behind the `serde` feature.
- Fuzz target exercising `Burst::parse` + round trip.

## Migration

No breaking changes. Initial release.
