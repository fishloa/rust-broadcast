# st377-1 0.1.0

**Release date:** 2026-07-12

Initial release. `st377-1` implements SMPTE ST 377-1:2019 "Material Exchange
Format (MXF) -- File Format Specification". This is the workspace's first
file-based interchange crate; every other crate here is live-stream-shaped.
It covers the format's backbone (KLV framing, Partition Packs, Primer Pack,
Random Index Pack) and the four Root Metadata Sets every real MXF file
contains.

## What's new

- `KlvItem` -- generic KLV triplet (16-byte Key + BER Length + Value),
  zero-copy. `walk_klv_items`/`collect_klv_items` for iteration.
- `ber` module -- BER length codec per ISO/IEC 8825-1 as constrained by
  MXF.
- `PartitionPack` -- fully typed Header/Body/Footer Partition Pack with
  `PartitionKind`/`PartitionStatus`, all Table 5 fields, and Operational
  Pattern/Essence Container UL batches.
- `PrimerPack` -- per-Partition local-tag-to-UL lookup table with
  `resolve_tag`/`resolve_ul`.
- `LocalSet`/`LocalSetItem` -- generic local-set framing; `StructuralSetKind`
  identifies all 27 Table 17 Set types.
- `Preface`, `Identification`, `ContentStorage`, `EssenceContainerData` --
  the four Root Metadata Sets, decoded field-by-field from static local tags.
- `RandomIndexPack`/`PartitionLocation` -- optional file-trailer Partition
  index.
- `types` module: `MxfTimestamp`, `ProductVersion`/`ReleaseType`, `Auid`,
  `PackageId`, UTF-16 BE string codecs, UID batch parse/serialize.
- Spec-derived synthetic fixture with multi-partition round-trip test.
- Two runnable examples: `parse_partition` and `build_preface`.
- `no_std` + `alloc`; builds on bare-metal targets.
- `serde` support behind the `serde` feature.
- Fuzz target covering KLV dispatch to all typed parsers.
