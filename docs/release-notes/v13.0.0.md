# v13.0.0

_Released 2026-11-07._

Lockstep **major** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 12.1.0 -> 13.0.0. Three things break for a downstream user: `serde` is no longer a default feature of `dvb-si` and `dvb-conformance`, the error enums wrap the shared failure kinds from `broadcast-common` 11, and `dvb-si` and `dvb-t2mi` replace `ReservedBitsViolation` with typed errors that carry the wire value (#1715). `dvb-tools` carries the version only.

**Order matters:** `broadcast-common-v11.0.0` must be live on crates.io before the `v13.0.0` tag is pushed, because all five lockstep crates depend on it.

## Highlights

- **Shared error kinds.** `BufferTooShort`, `OutputBufferTooSmall`, `CrcMismatch`, `InvalidSync`, `ReservedBits`, `InvalidValue`, `InvalidField`, `FieldOverflow`, `UnsupportedVersion` and `LengthMismatch` are defined once in `broadcast_common::error` and wrapped by each crate's error enum (#1701, #1706, #1707).
- **Typed reserved-bit and invalid-value errors (#1715).** `dvb-si` and `dvb-t2mi` no longer return a free-text `ReservedBitsViolation`; each failure is a typed error with the field, the expected value and the value found on the wire.
- **`serde` is opt-in.** No crate in the workspace enables it by default any more (owner decision 2026-11-07).
- **`dvb-si`:** `DtsDescriptor::bit_rate_bps`, `impl Serialize for AnyTableSection`, and the NIT and BAT transport-stream types merged into `tables::TransportStreamEntry` and `collect::CompleteTransportStream`.
- **Pipeline fixes in the companion crates:** `transmux` bumps the PMT `version_number` when its PMT changes (#1699, #1702), and `multimux` dynamic MPDs carry `MPD@publishTime` (#1704). See the `transmux` 0.30.0 and `multimux` 0.16.0 notes.

## Breaking changes and migration

### 1. `serde` is no longer a default feature (`dvb-si`, `dvb-conformance`)

```toml
# before
dvb-si = "12"
# after
dvb-si = { version = "13", features = ["serde"] }
```

`dvb-t2mi`, `dvb-bbframe` and `dvb-tools` never enabled it by default.

### 2. Error enums wrap shared kinds (all four library crates)

```rust
// before
Err(dvb_si::Error::BufferTooShort { need, have, what }) => eprintln!("{what}: need {need}, have {have}"),
Err(dvb_si::Error::InvalidSyncByte { found }) => eprintln!("sync byte {found:#04x}"),
Err(dvb_si::Error::CrcMismatch { computed, expected }) => eprintln!("{computed:#x} != {expected:#x}"),
// after
Err(dvb_si::Error::BufferTooShort(e)) => eprintln!("{}: need {}, have {}", e.what, e.need, e.have),
Err(dvb_si::Error::InvalidSync(e)) => eprintln!("{}: found {:#x}", e.what, e.found),
Err(dvb_si::Error::CrcMismatch(e)) => eprintln!("{}: {:#x} != {:#x}", e.what, e.computed, e.expected),
```

`From` impls exist for each shared struct, so `?` and `.into()` still build them. `dvb-bbframe` changes `BufferTooShort` and `OutputBufferTooSmall` only. The messages of these variants follow the common wording, and `CrcMismatch` gains a `what` naming the table (`"T2-MI packet"` for `dvb-t2mi`).

### 3. `ReservedBitsViolation` is replaced (`dvb-si`, `dvb-t2mi`, #1715)

```rust
// before
Err(Error::ReservedBitsViolation { field, reason }) => report(field, reason),
// after
Err(Error::ReservedBits(r)) => report(r.field, format!("expected {:#x}, found {:#x}", r.expected, r.found)),
Err(Error::InvalidValue(v)) => report(v.field, format!("{} ({})", v.reason, v.value)),
```

`dvb-si` also returns `InvalidSync` for the BIOP magic, `FieldOverflow` for an over-range MPE scrambling-control and `InvalidField` for a zlib failure; `dvb-t2mi` also returns `FieldOverflow`, `InvalidField` and `LengthMismatch` (see the per-crate CHANGELOGs for the exact mapping). The RFU policy of `dvb-t2mi` (reject non-zero RFU except individual addressing) is unchanged.

### 4. Removed public items

Unused public items, with no use in the workspace beyond their own unit tests, are removed: in `dvb-si` `COMPRESSED_MODULE_DESCRIPTOR_TAG`, `application_type_name`, `bit_rate_kbits`, `bit_rate_name`, `extended_surround_name`, `is_valid_pid`, `peid`, `phy_stream`, `sample_rate_name`, `serialize_into_at`, `surround_mode_name`, `table_section_with`, `tdm`, `usage_type_name`, `tables::nit::NitTransportStream`, `tables::bat::BatTransportStream`, `collect::CompleteNitTransportStream` and `collect::CompleteBatTransportStream`; in `dvb-t2mi` `drain_packets`, `guard_interval_set`, `inband_loop`; in `dvb-bbframe` `bufstat_bytes`.

```rust
// before
let kbit = dts.bit_rate_kbits();
let ts: tables::nit::NitTransportStream = /* .. */;
// after
let bps = dts.bit_rate_bps();
let ts: tables::TransportStreamEntry = /* .. */;
```
