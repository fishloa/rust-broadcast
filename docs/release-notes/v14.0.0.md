# v14.0.0

_Released 2026-11-14._

Lockstep **major** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 13.0.0 -> 14.0.0. The staged 13.1.0 was never published; its content ships here. Two reasons make this a major:

- **`dvb-si` breaking change:** the long-form table constructors take one `tables::SectionVersion` in place of four positional header arguments (#2612).
- **Epoch purity:** `broadcast-common` moves 11 -> 12 (its `ts_dup` module moved to `mpeg-ts`) and `mpeg-ts` moves 0.7 -> 0.8, so every lockstep crate builds against new caret epochs of its siblings, which is a major-class change on its own (docs/RELEASE-AUDIT.md section 2).

## Breaking changes and migration

`AitSection::new`, `CitSection::new`, `EitSection::new`, `IntSection::new`, `MpeIfecSection::new`, `NitSection::new`, `PmtSection::new`, `RctSection::new`, `RntSection::new`, `SatSection::new`, `SdtSection::new` and `UntSection::new` take a `dvb_si::tables::SectionVersion` where they took `version_number, current_next_indicator, section_number, last_section_number`:

```rust
// before
let pmt = PmtSection::new(1, 0, true, 0, 0, pcr_pid, program_info, streams);
// after
use dvb_si::tables::SectionVersion;
let pmt = PmtSection::new(1, SectionVersion::new(0, true, 0, 0), pcr_pid, program_info, streams);
```

A consumer that names `broadcast_common::ts_dup` directly imports `mpeg_ts::ts_dup` instead.

## Highlights

- **`dvb-si`:** `TableId`, `DescriptorTag` and `ExtensionTag` implement the workspace label convention (`name()` + `Display`); the published package ships a `skills/dvb-si-basics/SKILL.md` agent skill; the Satellite Access Table reader reports short input in bytes like every other `BufferTooShort`, and its writer is `broadcast_common::bits::BitWriter`.
- **`dvb-si` carousel/demux robustness:** `ModuleReassembler` no longer grows its completed-module FIFO per version and replaces a DII repeat announcing the same module version with changed geometry; `SiDemux` no longer appends a retransmitted continuation packet, keeps the full PMT PID watch set across multi-section PATs, ignores `current_next_indicator = 0` PATs, and keys its version gate on `current_next_indicator`.
- **`dvb-conformance`:** `ConformanceMonitor::indicator_counts` (with `IndicatorCount`) publishes per-indicator event counts; CRC-failed SI sections no longer mutate monitor state; `_other` repetition errors re-raise on every later outage; 2.3a/2.3b PCR checks sharpened (27 MHz comparison, silence detection, once-per-gap reporting); legal duplicate packets (now detected through `mpeg_ts::ts_dup`) are not fed to section reassembly; EIT P/F vanishing partner detected; PES packets without an optional header skipped in 2.5; EIT P/F pairing map bounded.
- **`dvb-tools`:** `pids` takes PCR wrap steps from `broadcast_common::clock33::pcr_signed_distance`, keeps the unwrapped PCR signed (no bogus bitrate after a backward step near zero), and file readers count the aligned tail packets of a capture.
- **`dvb-bbframe`:** `CarryOverExtractor`/`BbframePump` reset the NM CRC-8 chain and pending partial UP on a skipped frame; a `SYNCD=0xFFFF` frame keeps the data-field bytes after the UP it completes.
- **`dvb-t2mi`:** documentation only (the trailer CRC is `broadcast_common::crc32_mpeg2`); version moves with the lockstep and its sibling epochs.

See the per-crate notes for the full lists: `dvb-si-14.0.0.md`, `dvb-t2mi-14.0.0.md`, `dvb-bbframe-14.0.0.md`, `dvb-conformance-14.0.0.md`, `dvb-tools-14.0.0.md`.
