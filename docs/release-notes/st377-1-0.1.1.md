# st377-1 0.1.1

**Release date:** 2026-07-13

Patch release fixing three issues found by an adversarial PDF-fidelity audit
against the real SMPTE ST 377-1:2019 PDF.

## What's new

- Removed `StructuralSetKind::IndexTableSegment`: the variant never matched
  a real on-wire Index Table Segment (its Key uses a distinct family from the
  Local Set pattern, and the byte values were transposed relative to Table 25).
- `Preface::parse` no longer hard-requires `Identifications` (tag `0x3B06`):
  Annex A.2 marks it "E/req" (encoder-required, decoder-tolerant), not plain
  "Req".
- Fixed 4 collapsed Key hex-string shorthands in `docs/st377-1.md`, each
  missing one of two adjacent `0x01` bytes; fixed Preface's `Identifications`
  Req column.

## Migration

No breaking changes.
