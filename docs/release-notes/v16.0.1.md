# v16.0.1

_Released 2026-11-23._

Lockstep patch (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 16.0.0 -> 16.0.1. One of the five carries a fix; the other four are version-only and follow the family.

- `dvb-bbframe` 16.0.0 -> 16.0.1: `CarryOverExtractor` discards a carried partial user packet when the next frame's mode or stride differs, instead of underflowing `stride - pos` (#4049). See `dvb-bbframe-16.0.1.md`.
- `dvb-si`, `dvb-t2mi`, `dvb-conformance`, `dvb-tools` 16.0.0 -> 16.0.1: version only.
