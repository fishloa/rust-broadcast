# v12.0.1

_Released 2026-10-31._

Lockstep **patch** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 12.0.0 -> 12.0.1. There is no change to any parsed or serialized byte and no change to the public API with default features.

## What changed

- The optional `yoke` feature of `dvb-si`, `dvb-t2mi` and `dvb-bbframe` now derives `yoke` 0.8's `Yokeable` (it was 0.7). The feature is off by default and no crate in this workspace enables it. Only a consumer who enables `yoke` and names `yoke` 0.7 types directly needs to move its own `yoke` dependency to 0.8; everyone else upgrades with no change.
- Documentation citations in `dvb-si` and `dvb-t2mi` now point at paths that exist (`dvb-si/docs/README.md`, the private spec-transcription map) instead of moved files.
- `dvb-conformance` and `dvb-tools` carry the lockstep version only.
