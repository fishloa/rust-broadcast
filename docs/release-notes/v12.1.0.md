# v12.1.0

_Released 2026-11-02._

Lockstep **minor** (`dvb-si`, `dvb-t2mi`, `dvb-bbframe`, `dvb-conformance`, `dvb-tools`), 12.0.1 -> 12.1.0. `dvb-si` adds the ATSC caption service descriptor (tag 0x86) and the companion crates in this wave build on it for caption language discovery; the other four lockstep crates carry the version only.

## Highlights

- **`dvb-si`:** `descriptors::atsc_caption_service::AtscCaptionServiceDescriptor` (ATSC A/65:2013 Table 6.26): per-service `language`, typed `AtscCaptionKind` (608 with `line21_field`, 708 with `caption_service_number`), `easy_reader`, `wide_aspect_ratio`, every reserved run preserved. Tag 0x86 is context dependent (the China descriptor reuses it), so it is not auto-dispatched; enable it with `DescriptorRegistry::with_atsc_caption_service()`. `AnyDescriptor::AtscCaptionService` variant. Verified against the descriptor in `tsduck/input/test-040.ts`.
- **`transmux` / `hls-runtime` / `multimux`:** caption language discovery from the ATSC `caption_service_descriptor` in a video track's PMT loop (issue #1428), plus CEA-608 channel and CEA-708 service attribution and `CLOSED-CAPTIONS=NONE` handling.
- **`srt-runtime`:** encryption on the tokio rendezvous path and the data path, with KM refresh (#1653, #1658).
- **`broadcast-client`:** client certificates (mTLS), UDP, RTP, SRT, Smooth Streaming and RTMP sources (#1460, #1461, #1646, #1648, #1649, #1662).
- **`rtmp-runtime`:** play mode for the sans-IO client (#1460).
- **`cc-data`:** `Cea608Decoder::has_caption_text`, `Cea608Channel::number`, `Cea708Decoder::services_seen` (#1428).
