## Conventions used in these notes

- **Own wording.** Each file restates what a clause defines and the behaviour an implementer needs, with facts (names, Use codes, defaults, units, enumerations, URNs) kept exact. Spec paragraphs and table cell prose are not copied; a short term in quotes is the most that is quoted.
- **Inventory tables** use `Name | Use | Type | Default | Gloss`. Use codes are the spec's: `M` mandatory, `O` optional, `OD` optional with default, `CM` conditionally mandatory, `F` fixed; element rows give `min..max` occurrences (`N` = unbounded). Names: elements bare, attributes as `@code`.
- **Element-tree outlines** replace the spec's XML syntax blocks; schema types are summarised by attribute/child name and XSD type only.
- **Citations.** Every section heading names the clause; a "(p. N)" is the *printed* page (PDF page = printed + 8). Table numbers are the spec's.
- **Figures 1-3** are our own ASCII redraws with a page cite (04-overview.md).
- **Transcription notes** at the end of each file list the spec's own quirks (wrong cross-references, broken "subclause 0" fields, formula inconsistencies, typos), each described with its location.
- **Cross-references** to clauses covered here are relative links; other clauses are plain text.
