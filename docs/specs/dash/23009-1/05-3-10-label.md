# 5.3.10 Label and GroupLabel

## What it defines

Two small annotation elements that attach a short human-readable string to the element that contains them, intended for client UI such as a
selection menu. **Label** carries one string; **GroupLabel** carries a title for a set of labels. Both are the same XML type, `LabelType`
(text content plus two attributes).

## Normative behaviour

- Labels that share the same `@id` value form one label group; every label of one group has to sit on the same level of the MPD hierarchy (shall).
- `@lang` states the language of that label's text, so a client can filter by user language; when it is absent the language is unknown.
- A GroupLabel's `@id` has to be unique among all GroupLabels of the MPD, and has to equal the `@id` of the Labels it titles.
- Placement (from the 5.3 element tables, A-side notes): **GroupLabel** is a child of Period (0..N) and a common element (0..N) of Adaptation Set / Representation / Sub-Representation / Preselection; **Label** is a common element (0..N) of those same elements (Table 14, [`05-3-7-common.md`](05-3-7-common.md)).

## Inventory

| Name | Use | Type | Default | Gloss |
|---|---|---|---|---|
| Label (element content) | - | xs:string | - | the label text |
| Label@id | OD | xs:unsignedInt | 0 | label-group key |
| Label@lang | O | xs:language | absent = unknown | language of the text |
| GroupLabel (element content) | - | xs:string | - | the group's title text |
| GroupLabel@id | OD | xs:unsignedInt | 0 | must match the grouped Labels; unique per MPD |
| GroupLabel@lang | O | xs:language | absent = unknown | language of the title |

Both accept extension attributes from other namespaces (lax).

## Structure outline

```text
LabelType  = simple content, base xs:string
  @id   xs:unsignedInt  default 0
  @lang xs:language
  @*    any attribute from ##other (lax)
```
