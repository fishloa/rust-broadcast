# Documentation index

Workspace-level documentation. Each crate's own documentation is its
`README.md` (also its crates.io page), its docs.rs page, its `CHANGELOG.md`, and
the spec transcriptions in its `docs/` directory.

## Start here

| Document | What it answers |
|---|---|
| [CRATES.md](CRATES.md) | Every crate: what it does, standards, `no_std`, crates.io status, dependencies, and "which crate do I use for X". Mostly generated by `tools/gen-crate-index.py`. |
| [STANDARDS.md](STANDARDS.md) | Every standard: which crate implements it, which edition, how completely, where the transcription lives. |
| [HLS-SUPPORT.md](HLS-SUPPORT.md) | What the workspace implements of HTTP Live Streaming, and what it does not. |
| CHINESE-STANDARDS.md | The Chinese broadcast and AVS standards: what was acquired, editions, discrepancies between sources. |

## Specifications

Freely redistributable text specs (RFCs, W3C, HLS drafts) are in
`../specs/`, with the list of vendored PDFs in
`../specs/README.md`. The PDFs themselves are in the
private `private/` submodule (maintainers only). The Markdown transcriptions the
code is checked against are public, in each crate's `docs/` directory; the
[STANDARDS.md](STANDARDS.md) Transcription column links them.
