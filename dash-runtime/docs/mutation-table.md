# Mutation table

Each mutant is a one-line change to the production source of this crate, applied on its own, followed by a full
`cargo test -p dash-runtime --locked --no-fail-fast` (the run recompiled the crate: `Compiling dash-runtime` appeared
in every run) and then reverted. A mutant is **killed** when at least one test fails. The first column is the
mutant id, the last lists the tests that failed (first four).
