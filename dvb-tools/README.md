# dvb-tools

[![crates.io](https://img.shields.io/crates/v/dvb-tools.svg)](https://crates.io/crates/dvb-tools)
[![License](https://img.shields.io/badge/license-MIT%20OR%20Apache--2.0-blue.svg)](#related-crates-and-license)

**`dvb-tools`: a command-line DVB transport-stream analyzer (`dump`, `services`, `epg`, `pids`, `t2mi`) built on the rust-broadcast library crates.**

## What it does / what it does not

`dvb-tools` is a std-only **binary crate** (no library API). Point it at a
`.ts` capture and it decodes the Service Information the stream carries: every
PSI/SI section with its descriptor loops (`dump`), the service tree with
logical channel numbers (`services`), the EIT schedule (`epg`), a PID table with
bitrate (`pids`), and T2-MI packets or the inner transport stream they carry
(`t2mi`). It is for engineers inspecting captures, for scripting (`--json`), and
as the reference consumer of `dvb-si`, `dvb-t2mi` and `mpeg-ts`.

It reads files only (every subcommand streams the capture in 1 MiB reads through
the stateful TS resynchroniser, so a 152 MB capture needs about 19 MB of memory).
It does not monitor live streams (see `compliance-probe`), check TR 101 290
conformance (see `dvb-conformance`), repair streams (see `ts-fix`), or diagnose
containers (see `media-doctor`).

## Standards supported

The tool adds no wire format of its own; it reports what the library crates
decode.

| Standard | Edition | Scope | Status | Notes |
|---|---|---|---|---|
| ETSI EN 300 468 (DVB SI) | via `dvb-si`: V1.19.1 / V1.20.1 vendored | All allocated tables and the descriptors `dvb-si` implements; SDT/NIT service tree; EIT schedule | Full (as `dvb-si`) | Subcommands: `dump`, `services`, `epg`. |
| NorDig / EACEM logical channel number descriptors | edition unverified (not vendored) | LCN shown by `dump` and `services` | Partial | Whatever `dvb-si` decodes for these private descriptors. |
| ITU-T H.222.0 / ISO/IEC 13818-1 | H.222.0 v9 (08/2023) | PAT/PMT/CAT/TSDT, PID table, PCR-based bitrate | Full for PSI | `pids` bitrate is `n/a` when at most one PCR is seen. |
| ETSI TS 102 773 (T2-MI) | V1.4.1 via `dvb-t2mi` | `t2mi` packet dump; `--inner` recovers the inner TS through `dvb-bbframe` | Full (as `dvb-t2mi`) | HEM frames with NPD are skipped. |

## Command line

Install or run from the workspace: `cargo run -p dvb-tools --locked -- <command> ...`.
Help is generated by `clap` per the workspace [CLI standard](https://github.com/fishloa/rust-broadcast/blob/main/docs/CLI-STANDARD.md).

```text
$ dvb-tools --help
Command-line DVB stream analyzer (dump / services / epg / pids / t2mi) over the rust-broadcast crates.

Usage: dvb-tools <COMMAND>

Commands:
  dump      SI section dump — decodes PMT/SDT/NIT descriptor loops (incl. NorDig/EACEM LCN)
  services  SDT + NIT/LCN service tree
  epg       EIT schedule
  pids      PID table + bitrate
  t2mi      T2-MI dump, or inner-TS extraction with `--inner`
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
```

```text
$ dvb-tools t2mi --help
T2-MI dump, or inner-TS extraction with `--inner`

Usage: dvb-tools t2mi [OPTIONS] <FILE>

Arguments:
  <FILE>  Input file (`.t2mi` raw, or a `.ts` carrying T2-MI)

Options:
      --pid <PID>  T2-MI source PID (`0x`-hex or decimal), or `raw` for a bare T2-MI byte stream. Defaults to 0x0006
      --inner      Recover and write the inner MPEG-TS to stdout (pipe to `dump`)
      --plp <PLP>  With `--inner`, keep only this PLP
  -h, --help       Print help
```

`dump` and `epg` take `--json` (each decoded table as pretty JSON instead of a
summary line); `dump` accepts 188- or 204-byte packet files.

### Example invocations (committed fixtures, run from the repository root)

```console
$ dvb-tools dump fixtures/ts/m6-single.ts
pid=0x0000 PROGRAM_ASSOCIATION v0 sn=0
pid=0x0064 PROGRAM_MAP v1 sn=0
    es pid=0x0078 stream_type=H.264/AVC
    es pid=0x0082 stream_type=PES Private Data
      desc ISO_639_LANGUAGE
      desc ENHANCED_AC3
...

$ dvb-tools pids fixtures/ts/m6-single.ts
pid=0x0082  packets=418  33.07%
pid=0x0084  packets=351  27.77%
...
-- total_packets=1264  bitrate=n/a (<=1 PCR seen)

$ dvb-tools services fixtures/dvb-si/tnt-5w-12732v-isi6-10s.ts
LCN    1  onid=0x20FA tsid=0x0006 service=0x0601  H.264/AVC HD digital television service  "TF1"  running=running
...
-- services=5 with_lcn=5 sdt_collected=1 nit_collected=1

$ dvb-tools epg fixtures/dvb-si/tnt-5w-12732v-isi6-10s.ts
service 0x0601  TF1
    event_id=0x7857  start=2026-04-11T00:45:00+00:00  duration=0h32m00s  "50' inside. "Le mag" (55/106)"
...
```

T2-MI: dump the packets of a capture, or extract the inner transport stream and
analyse its SI in a pipeline:

```console
$ dvb-tools t2mi fixtures/dvb-t2mi/colombia-capital-t2mi.ts --pid 0x0040
type=BBFRAME (0x00) count=231 superframe_idx=15 stream_id=0 payload_bits=38712
...

$ dvb-tools t2mi fixtures/dvb-t2mi/colombia-capital-t2mi.ts --pid 0x0040 --inner > inner.ts
-- inner packets written: ts_packets=6000 t2mi_packets=258 crc_failures=0 malformed=0
$ dvb-tools dump inner.ts
...
-- packets=5756 sections=39 emitted=5 suppressed=34 crc_failures=0 malformed=0
```

Without `--plp`, `t2mi --inner` scans the capture first and exits non-zero (listing
the PLPs) when it carries more than one: each PLP is an independent transport
stream, so choose one with `--plp N`. A closed stdout pipe (`| head`) is a clean
stop.

## What is implemented

| Subcommand | Library crates used | Output |
|---|---|---|
| `dump <FILE> [--json]` | `dvb-si` (`SiDemux`, descriptor decoding), `mpeg-ts` | One line per emitted section (version-gated: unchanged sections are suppressed and counted), with PMT/SDT/NIT descriptor loops expanded; a summary line of packets, sections, CRC failures, malformed sections |
| `services <FILE>` | `dvb-si` | SDT + NIT service tree with LCN, service type and running status |
| `epg <FILE> [--json]` | `dvb-si` | EIT schedule grouped by service |
| `pids <FILE>` | `mpeg-ts`, `broadcast-common` (`clock33`) | Packets and share per PID, PCR-derived bitrate |
| `t2mi <FILE> [--pid] [--inner] [--plp]` | `dvb-t2mi`, `mpeg-ts` | T2-MI packet dump, or inner TS on stdout |

## Design notes

- Binary only, `clap` derive with named flags and automatic `--help`/`--version`
  (workspace CLI standard); a std-only crate (no `no_std` claim).
- Streaming, bounded memory; mid-file read errors are reported and exit non-zero.
- PCR arithmetic is `broadcast_common::clock33` (`tests/clock33_guard.rs`).
- Regression tests: `tests/smoke.rs`, `pids_bitrate_oracle.rs`,
  `services_shared_service_id.rs`, `t2mi_typed_pid.rs`, `stdout_closed.rs`.
